### 🚀 Featured Project

**AWS Automated Security Detection & Response System**

A cloud security monitoring and alerting pipeline designed to simulate automated security event detection and response.

- 🔹 Event-driven architecture using Amazon EventBridge.
- 🔹 SQS for reliable message queuing and decoupling.
- 🔹 SNS for security alert notifications.
- 🔹 Python (Boto3) for event processing and automation.
- 🔹 Docker & LocalStack for local AWS service simulation.
- 🔹 SQLite for event tracking and duplicate prevention.
